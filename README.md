# FinCo: AI-Native Fintech Operations Framework

This is a governance and AI-agent operating system I designed for an early-stage AI-native fintech startup (name changed for confidentiality) doing automated financial outreach. Read this as a framework, not a live company.

> **Disclaimer:** Company names, product names, and personal data in this repo are fictionalized to protect confidentiality. The methodology, structure, and outcomes are real.

---

## How to navigate this repo

| If you are... | Start with... |
|---|---|
| New to the framework | `START-HERE.md` → relevant agent in `Agents/` |
| Agent (Atlas, Conductor) | `START-HERE.md` → your agent file |
| Ops / Chief of Staff | `START-HERE.md` → `Governance/` |
| Dev / Lead Engineering | `Dev/Methodology.md` |

## Structure

```
FinCo-OS/
├── START-HERE.md           ← Agent index and workflows
├── AGENTS.md               ← Working rules for agents
├── Governance/             ← Policies (POL), SOPs, templates, roles, gates
├── Agents/                 ← Definition of each AI agent
├── Agents/Workflows/       ← Step-by-step procedures for agents
├── Dev/                    ← Methodology, cycles, roadmap
└── Operations-Samples/     ← Monitoring templates and review samples
```

---

## PDCA philosophy

Every process has a Plan → Do → Check → Act cycle. No process without an owner, no owner without evidence, no evidence without a record.
