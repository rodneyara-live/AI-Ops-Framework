# Developer

## Role purpose

The Developer has technical ownership over assigned FinCo components. They implement features, automations, and agentic flows with sufficient autonomy to make implementation decisions independently, communicate blockers clearly, and deliver reviewable work without micro-management.

---

## Responsibilities

**Development and implementation**
- Implement features, automations, and agentic flows within the FinCo stack
- Translate backlog requirements into concrete technical solutions, raising questions before starting if the spec is unclear
- Maintain and evolve assigned products as technical DRI
- Write clean, documented, reviewable code

**Quality and delivery**
- Submit work for technical review before merge; no exceptions
- Detect and report active technical debt to Lead Engineering
- Participate in production incident diagnosis when required
- Ensure changes comply with relevant compliance technical requirements (rate limiting, audit log, automated system identification)

**Collaboration**
- Participate in the weekly Team Sync and Friday planning session
- Keep Linear updated with the real status of assigned items
- Request technical review from Lead Engineering on design decisions that exceed the item's usual scope

---

## Role competencies

**Technical**
- Building and maintaining backend integrations: APIs, databases, automations
- Fluency with version control tools (Git/GitHub) and code review
- Judgment to distinguish when a solution is sufficient and when it needs improvement

**Operational**
- Autonomy: takes a backlog item, understands it, implements it, and reports the result
- Clear written communication, in a 100% remote team this is a technical competency
- Honest time management: does not over-promise, does not under-report

---

## Stack

Supabase · N8N · GitHub · Linear · Slack · Python / Node.js · Docker · Claude API · ElevenLabs · WATI
