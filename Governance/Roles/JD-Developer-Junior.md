# Developer Junior

## Role purpose

The Junior Developer operates within FinCo's technical team under active supervision from Lead Engineering. They work on real product items from the first cycle, with a narrower scope and a more frequent review cycle than the Developer. The role is designed to develop progressive technical autonomy.

---

## Responsibilities

**Development**
- Implement features and integrations of defined scope, under Lead Engineering review
- Write functional, commented, readable code
- Execute assigned backlog items, proactively communicating blockers and spec doubts
- Assume ownership of components as confidence and technical judgment grow

**Quality**
- Submit all work for code review before merge; no exceptions
- Report to Lead Engineering when an item turns out more complex than expected, rather than blocking silently
- Write code understandable by another developer, not merely functional for the moment

**Collaboration**
- Participate in the weekly Team Sync and Friday planning session
- Keep Linear updated with the real status of assigned items
- Ask questions before implementing when the spec is ambiguous

---

## Role competencies

**Technical**
- Basic backend understanding: APIs, relational databases, automation scripts
- Basic Git: branches, clear commits, opening PRs
- Ability to read and understand existing code before modifying it

**Operational**
- Genuine willingness to receive and apply technical feedback
- Clear, proactive written communication about work status
- Active curiosity about the stack and the AI agent space

---

## Trajectory

The expected trajectory to the Developer role is 12 to 18 months, subject to demonstrated technical autonomy and production judgment.

---

## Stack

Supabase · N8N · GitHub · Linear · Slack · Python / Node.js · Docker · Claude API · ElevenLabs · WATI
